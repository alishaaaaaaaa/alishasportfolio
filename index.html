    Roomify

  2. 02

    IC-PC Aneurysm Clipping Simulator

    A browser-based simulator of microsurgical brain aneurysm clipping, seen through an operating microscope. In English and French.

    • Six guided surgical steps with a mentor, live vitals and an end-of-case debrief
    • Ten instruments, including Doppler, ICG and an endoscope
    • Procedural anatomy and a bleeding, flow and rupture model, backed by tests
    • TypeScript
    • three.js
    • Web Audio
    • Vitest
    code ↗
  3. 03

    EchoCases

    An AI-powered cold case platform that surfaces hidden connections between unsolved cases across time and place.

    • Semantic matching with sentence embeddings finds cases with similar narratives across jurisdictions
    • HDBSCAN clustering flags possible crime series that were never linked
    • Interactive Mapbox map with an animated timeline and Gemini-powered analysis
    • Python
    • Flask
    • React
    • scikit-learn
    • Mapbox
    • Gemini
